# Поток

«Поток» — автономный прототип системы электронного документооборота: реестр документов, карточки, маршруты согласования, задачи, поиск и архив.

## Возможности

- рабочий стол с приоритетными задачами;
- реестр и поиск документов;
- фильтрация по статусам;
- создание карточки документа;
- просмотр маршрута согласования;
- согласование и перенос в архив;
- локальное сохранение данных в браузере;
- адаптивный интерфейс для компьютера и телефона.

## Запуск

Откройте `dist/index.html` в браузере или запустите любой статический HTTP-сервер из папки `dist`.

## Важно

Это демонстрационный MVP. Для промышленного использования потребуются серверная база данных, корпоративная авторизация, разграничение доступа, резервное копирование, антивирусная проверка файлов и интеграция с электронной подписью.
