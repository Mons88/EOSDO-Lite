# ЕОСДО Lite

Новая реализация прототипа Единой отраслевой системы электронного документооборота, построенная с нуля по руководству пользователя «ЕОСДО 2.0», версия 1.0.

Реализовано в автономном MVP:
- рабочий стол, задачи и уведомления;
- реестр и карточки документов;
- создание проектов документов по типам;
- согласование, подписание, регистрация, доработка и аннулирование;
- очереди согласования/подписания;
- файлы и связанные документы;
- поручения;
- договоры, доверенности, архив;
- корпоративная информация;
- справочники;
- поиск и отчёты;
- замещение;
- имитация УКЭП.

Данные сохраняются локально в браузере (localStorage). Для промышленной эксплуатации необходим серверный backend, корпоративная IAM/SSO, СУБД, файловое хранилище, аудит, реальная УКЭП и интеграции.
